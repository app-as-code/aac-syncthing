# Icon source

Icons are downloaded from the homarr-labs dashboard-icons collection
(repository `homarr-labs/dashboard-icons`, served via jsdelivr). No icon was drawn or
modified by hand.

| File in this repo | Upstream file | Used for |
|---|---|---|
| `icon.svg` | `svg/syncthing.svg` | Default fallback (white mark on blue) |
| `icon-dark.svg` | `svg/syncthing.svg` | Shown in dark mode (white mark) |
| `icon-light.svg` | `svg/syncthing-dark.svg` | Shown in light mode (dark mark) |

Download URLs:

- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/syncthing.svg
- https://cdn.jsdelivr.net/gh/homarr-labs/dashboard-icons/svg/syncthing-dark.svg
